# 系统窗口检测器

这是一个用于检测系统窗口的Python程序，支持多种检测方法。

## 功能特点

1. Win32多维度检测
2. 调试端口直连检测
3. NDIS网络驱动检测
4. 内存特征扫描检测

## 安装步骤

1. 确保已安装Python 3.7或更高版本
2. 安装依赖包：
   ```bash
   pip install -r requirements.txt
   ```

## 使用方法

1. 运行程序：
   ```bash
   python window_detector.py
   ```

2. 在程序界面中选择检测方法
3. 点击"开始检测"按钮
4. 查看检测结果

## 注意事项

1. Win32多维度检测需要管理员权限
2. 调试端口直连检测需要先启动浏览器的调试模式
3. NDIS网络驱动检测需要额外配置
4. 内存特征扫描检测需要管理员权限

## 系统要求

- Windows 10或更高版本
- Python 3.7+
- 管理员权限（部分功能需要）
